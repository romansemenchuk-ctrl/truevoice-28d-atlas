# TrueVoice Atlas · 3.0

Інтерактивний атлас для 28-денного курсу Романа Семенчука. HTML/CSS/JavaScript без runtime-фреймворків. Файл `js/data/lessons.js` з авторськими текстами не змінювався.

## Оновлення

Чотири художні анатомічні ілюстрації: голосовий тракт, дихання, гортань та вісь тіла. Перемикач «Ілюстрація / Схема», інтерактивні зони з поясненнями, підписи, масштаб 100–300%, перетягування після збільшення, розгорнутий перегляд і клавіатурне керування. Ілюстрації не деформуються разом із дихальним ритмом: рух відображається на окремих спрощених схемах.

Дихальний тренажер використовує фактичну тривалість фаз, пропускає нульові паузи та зупиняється у прихованій вкладці. Ритм за замовчуванням — 5/0/5/0, без затримок. Це навчальний візуальний орієнтир, не індивідуальний медичний протокол.

Таймери практики підтримують паузу/продовження. Завершення кроку ідемпотентне: повторне проходження не знімає попередню відмітку. Закриття фокус-режиму очищує таймер. Нотатки зберігаються під час введення; перемикання уроку не втрачає останній текст.

Запис голосу очікує готовності IndexedDB, перевіряє підтримуваний MIME-формат, обробляє відмову в дозволі, скасування запиту мікрофона та помилки збереження. Потоки мікрофона й AudioContext закриваються. Завантаження використовує відповідне розширення аудіофайлу. Записи не надсилаються на сервер.

Фонове оформлення працює в одному циклі анімації, враховує приховану вкладку та системне зменшення руху. Декоративна хвиля не видається за вимірювання голосу. Синтетичні тони не позиціонуються як «частоти органів», записи голосних чи лікування.

## Запуск

Потрібні Node.js 20.9+ та Python 3 для локального HTTP-сервера. Встановлення runtime-залежностей не потрібне.

```sh
npm run build
python3 -m http.server 8080 --directory dist
```

Відкрити `http://localhost:8080`. Не відкривати `index.html` через `file://`: модулі та доступ до мікрофона потребують відповідного HTTP/HTTPS-контексту. Публічне розгортання повинно використовувати HTTPS.

## Ілюстрації та відтворювана збірка

Чотири AI-generated художні ілюстрації підготовлені для цього оновлення. Кожна має розмір 1122 × 1402; загальний розмір WebP — 911 434 байти, замість приблизно 8,9 МБ вихідних PNG.

`scripts/build.mjs` отримує фіксований пакет з медіасховища користувача, перевіряє SHA-256 пакета та кожної ілюстрації, і розміщує файли у `dist/assets/anatomy/`. Браузер отримує ілюстрації з того самого сайту, не з зовнішнього CDN. Збірка з чистого checkout потребує доступності початкового медіасховища; це не повністю автономний вихідний репозиторій з вбудованими бінарними файлами.

Пакет кешується в `.cache/atlas-artwork.json`. Для архівування зберегти цей файл разом з репозиторієм. Офлайн-збірка зі збереженим пакетом:

```sh
ARTWORK_PACK=/absolute/path/atlas-artwork.json npm run build
```

Очікуваний SHA-256: `c333edc10d3440ff9b5e94ed9a0226e9a51c600d3da6baedd5bda6ee77cb9b8e`.

Google Fonts залишаються зовнішньою залежністю оформлення; системні fallback-шрифти задані.

## Дані та резервні копії

Прогрес і нотатки зберігаються у `localStorage` під сумісним ключем `truevoice:atlas:v2`. Аудіо — у локальній IndexedDB `TrueVoiceRecordings`. Очищення даних браузера, зміна пристрою або домену не переносить дані автоматично. Прев’ю та основний сайт мають різні сховища через різні origin.

Експорт JSON містить прогрес, налаштування та нотатки, але не аудіозаписи. Аудіо потрібно завантажити окремо. Пошкоджений імпорт не замінює наявний стан. Скидання прогресу потребує підтвердження; аудіо не видаляється разом із прогресом.

## Перевірки

`tests/smoke.cjs` містить 16 автоматизованих браузерних сценаріїв: 28 уроків; 4 ілюстрації; інтерактивні зони; масштабування; дихальні фази; нотатки; ідемпотентні таймери; фокус-режим; пошук; імпорт; швидкі перемикання аудіо; запис/збереження; прихована вкладка; прямі посилання; ширини 320/390/768/1440; reduced-motion та відсутність неперехоплених JS-помилок. Частина перевірок об’єднана в одному сценарії.

```sh
npm install --no-save playwright
npx playwright install chromium
# В окремому терміналі запустити HTTP-сервер dist на порту 8080.
npm run test:browser
```

`ATLAS_URL` дозволяє тестувати інше розгортання. Тести змінюють лише ізольований браузерний профіль Playwright і використовують синтетичний мікрофон. Результат — `/tmp/atlas-qa.json`; скріншоти — `/tmp/atlas-desktop.png`, `/tmp/atlas-mobile.png`, `/tmp/atlas-workbench.png`. На Windows слід змінити шляхи результатів у тестовому файлі.

Не перевірено на фізичному iPhone, Safari або Firefox. Перевірка Chromium не гарантує сумісності з усіма браузерами, реальними аудіопристроями чи екранними читачами.

## Межі анатомічної точності

Це художня анатомічна візуалізація, не клінічно валідований медичний атлас. Світлові осі, Сонце/Місяць та енергетичні вузли — метафори бренду. Схеми спрощені; рух голосових складок умовний і сильно сповільнений. Відповідність деталей згенерованих ілюстрацій реальній анатомії потребує окремого фахового перегляду перед використанням як точного анатомічного довідника.

Усі вихідні уроки збережені. Це технічне й візуальне оновлення, а не повний науковий аудит їхніх тверджень. Традиційні авторські карти винесені окремо від анатомічного дослідника.

Базові пояснення нового анатомічного шару:
- NIDCD: https://www.nidcd.nih.gov/health/taking-care-your-voice
- NHLBI: https://www.nhlbi.nih.gov/health/lungs/breathing-benefits
- MDN: https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame

## Розгортання

`vercel.json` запускає `node scripts/build.mjs`, публікує `dist` та прибирає річний immutable-cache для змінюваних JS/CSS-файлів. В HTML додаються версії статичних ресурсів. Внесені зміни перебувають у гілці `upgrade/anatomy-interactive-20260908`; Git-інтеграція створює окремі Vercel Preview deployments. Основна гілка/production цим оновленням автоматично не зливаються.
